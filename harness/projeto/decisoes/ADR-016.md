# ADR-016 — Suíte em contêiner único, sem rede, com PostgreSQL local

Status: proposta (arquiteto: Eric) · Baseline: 2026-11-03.1 · Requisitos: nenhum (decisão de processo: isolamento da suíte, P1 do agente 3)

## Contexto
A P1 do agente 3 exige que a suíte rode em contêiner efêmero e sem rede (`docker run --rm --network none`). O plano pede testes de integração da Api com banco real em contêiner. Com `--network none`, um PostgreSQL em outro contêiner fica inalcançável, e `pnpm install` não consegue baixar nada. No Windows, o `node_modules` do host (com links do pnpm e binários nativos do Windows) não serve dentro do Linux.

## Decisão
- Uma imagem só, `math-scape-testes` (`infra/testes/Dockerfile`), com Node 24, PostgreSQL já inicializado (sem senha, só no loopback) e as dependências instaladas pelo `pnpm-lock.yaml`. É construída com rede (`pnpm testes:imagem`) e executada sem rede.
- A execução monta o repositório em `/src` e copia o código, sem `node_modules`, `.git` nem `harness/`, por cima das dependências da imagem (`infra/testes/entrada.sh`). Se o lockfile mudou desde a construção, a execução falha como ambiente e pede para reconstruir.
- Modo `testes`: sobe o PostgreSQL, cria `math_scape_teste`, aplica o esquema Prisma quando existir (`prisma generate` e `prisma migrate deploy`; sem migrations, `db push`) e roda `vitest run`. Com migrations, o banco da suíte tem o `CHECK` e os índices escritos em SQL (LAC-028). O relatório JUnit volta para `harness/estado/junit.xml`.
- Modo `analise`: Biome (lint) e verificação de tipos dos cinco pacotes; é o `comando_analise` do agente 4.
- Códigos de saída: 0 verde, 1 vermelho, 3 ambiente (o harness conta 3 falhas de ambiente seguidas como disjuntor).
- Comandos no config: `docker run --rm --network none -v .:/src math-scape-testes testes` e `... analise`.

## Consequências
- Uma execução vazia leva cerca de 7 s; o banco começa limpo em toda execução. Entre testes, `tests/support/banco.ts` esvazia as tabelas.
- Os arquivos de teste da Api rodam em sequência (`fileParallelism: false`), porque o banco é um só.
- Adicionar dependência exige reconstruir a imagem; o agente 4 não consegue, por construção (manifestos fora do escopo).
- A suíte Playwright (fases 5-6, navegadores reais) não roda nesta imagem; terá a sua própria quando for escrita.
