# ADR-006 — Palco 16:9 com coordenadas relativas

Status: proposta (arquiteto: Eric) · Baseline: 2026-11-03.1 · Requisitos: RF-03, RNF-01, RNF-02

## Contexto
RNF-02: sala em 16:9 com posições relativas, escalando a partir de 1280x720. RNF-01: abaixo de 1280x720, aviso. RF-03: a área mantém a proporção ao redimensionar.

## Decisão
- `x`, `y`, `largura`, `altura` dos objetos são números entre 0 e 1, relativos à parede; o schema recusa valores fora do intervalo.
- Editor e player usam o mesmo componente de palco: calcula o maior retângulo 16:9 que cabe no contêiner e multiplica as coordenadas por ele.
- Abaixo de 1280x720 de janela, os dois apps mostram um aviso (não bloqueiam).

## Consequências
- Imagens de fundo são desenhadas cobrindo o palco 16:9; recorte fica a cargo do criador.
- Navegadores (parte 1 do RNF-01): alvo de build `browserslist` = "last 2 Chrome versions, last 2 Edge versions, last 2 Firefox versions". O E2E roda o fluxo criar → publicar → jogar em três projetos Playwright (chromium, msedge, firefox). Só APIs suportadas nos três: canvas 2D, WebP, `fetch`, cookies.
