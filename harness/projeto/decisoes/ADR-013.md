# ADR-013 — Exportação autocontida

Status: proposta (arquiteto: Eric) · Baseline: 2026-11-03.1 · Requisitos: RF-14, RF-19, RNF-09

## Contexto
Achado da LAC-007. RF-14: exportar e importar o mesmo arquivo gera fase igual. Se o JSON só citar `asset:<uuid>`, a fase importada depende de imagens do autor, que somem quando ele exclui a conta (RF-19) ou quando o arquivo vai para outra instalação.

## Decisão
- O arquivo exportado é um envelope `{ formato: "math-scape-fase", versao: 1, fase, imagens: { "<uuid>": "data:image/...;base64,..." } }` com todas as imagens `asset:` usadas. Sprites (`sprite:`) não são embutidos.
- Importar valida o envelope e a fase pelo schema (RNF-09), grava cada imagem como asset novo do importador (mesmas regras do RF-06: tipo pelo conteúdo, até 5 MB cada), reescreve as referências e cria a fase. Qualquer falha recusa a importação inteira, sem gravação parcial.

## Consequências
- O arquivo exportado pode chegar a algumas dezenas de MB; o limite de corpo de `POST /fases/importar` é 50 MB.
- Uma fase importada não depende mais da conta do autor.
