# ADR-005 — Autorização por dono em toda rota de escrita e exportação

Status: proposta (arquiteto: Eric) · Baseline: 2026-11-03.1 · Requisitos: RF-02, RF-14, RF-19

## Contexto
RF-02: tentar alterar fase de outro criador, pela interface ou pela API, é recusado. RF-14: exportar fase de outro criador é recusado (protege as respostas). RF-19: excluir conta de outro usuário é recusado.

## Decisão
- Um único pré-handler Fastify `exigirDono` carrega a fase e compara `dono_id` com o usuário da sessão em toda rota `/fases/:id` exceto `verificar` sem `modo=teste`.
- Resposta 404 (não 403) para fase de outro dono, para não revelar a existência de rascunhos alheios.
- `DELETE /auth/conta` não recebe id: sempre age sobre o usuário da sessão.

## Consequências
- Um teste de integração por rota cobre o caso "usuário B tenta mexer na fase de A".
